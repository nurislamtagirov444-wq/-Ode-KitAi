# Карта ресурсов для исследования (2024-2026)

Для выполнения глубокого поиска Архитектор-Стратег должен обращаться к следующим узлам:

1. **Технические форумы:**
   - [4PDA](https://4pda.to) — для настройки Tecno Camon и софта.
   - [XDA Developers](https://www.xda-developers.com) — глубокая кастомизация Android.
   - [Reddit](https://reddit.com) (r/selfhosted, r/freebies, r/LocalLLama).

2. **Поиск бесплатных нейросетей:**
   - [Arena.ai](https://arena.ai) — приоритетный доступ к моделям.
   - [Hugging Face Spaces](https://huggingface.co/spaces) — бесплатные демо моделей.
   - [GitHub-проекты](https://github.com) с тегом `free-ai-api`.

3. **Специфические RU-ресурсы:**
   - Ответы Mail.ru (для бытовых лайфхаков и обхода ограничений).
   - Habr / VC.ru — кейсы 2024-2025 гг.

4. **Инструментарий:**
   - Moonlight/Sunshine для стриминга с облачного ПК.
   - Бот-фермы в Telegram.
