# Быстрый старт: бесплатный доступ, моды и стратегия

Инструкция для новичка. Каждый шаг: что сделать, зачем, точная команда,
нормальный результат, что делать если результат другой.

Проверено 27 июля 2026. Лимиты провайдеров меняются — команда `doctor`
всегда показывает реальное положение дел, а не то, что написано в тексте.

---

## Честно про «бесплатно и безлимитно»

Полностью бесплатного, быстрого и безлимитного облака не существует.
Всегда есть один из этих лимитов:

| Что выбираешь | Что получаешь | Чем платишь |
|---|---|---|
| Бесплатное облако | Скорость, ничего не устанавливать | Лимит запросов в сутки, данные уходят на чужой сервер |
| Локальный запуск | Нет лимита на количество запросов, приватность | Скорость упирается в твоё железо, электричество, качество модели ниже |

Самое близкое к безлимиту — **связка обоих**: сначала быстрое бесплатное
облако, а когда суточный лимит кончился, запрос сам уходит на локальную
модель. Именно это делает профиль `balanced`, включённый по умолчанию.

## Шаг 0. Проверить, что Python на месте

**Что сделать:**

```bash
python3 --version
```

**Зачем:** весь набор написан на чистом Python без сторонних библиотек.
Ничего ставить через pip не нужно.

**Нормальный результат:** `Python 3.9.x` или новее.

**Если другой результат:** `Python: command not found` — установи Python
с https://www.python.org/downloads/ (Windows) или `sudo apt install python3`
(Linux). На Android в Termux: `pkg install python`.

## Шаг 1. Бесплатный доступ к моделям

Выбери минимум один путь. Можно оба — тогда будет запас.

### Путь A. Облако Groq (быстро, 5 минут, карта не нужна)

**Что сделать:**

1. Открой https://console.groq.com
2. Войди через GitHub-аккаунт (он у тебя уже есть)
3. Раздел **API Keys** → **Create API Key** → скопируй значение
4. Выполни:

```bash
python3 kitai_cli.py key set GROQ_API_KEY
```

5. Вставь ключ в приглашение. Ввод скрыт — символы не отображаются, это нормально.

**Зачем:** Groq даёт самую быструю бесплатную генерацию, и его хватит,
чтобы пользоваться агентом с телефона без нагрузки на устройство.

**Нормальный результат:**

```
Сохранил в /путь/.env (права 600). Проверь: python3 kitai_cli.py doctor
```

**Реальные лимиты Groq** (официальная таблица https://console.groq.com/docs/rate-limits):

| Модель | Запросов/мин | Запросов/сутки | Токенов/сутки |
|---|---|---|---|
| `llama-3.1-8b-instant` | 30 | 14 400 | 500 000 |
| `llama-3.3-70b-versatile` | 30 | 1 000 | 100 000 |
| `openai/gpt-oss-20b` | 30 | 1 000 | 200 000 |
| `openai/gpt-oss-120b` | 30 | 1 000 | 200 000 |

**Если результат другой:** ошибка `Неизвестная переменная` — проверь, что
пишешь имя точно `GROQ_API_KEY` заглавными буквами.

### Путь B. Локально через Ollama (без лимитов на количество)

**Что сделать:**

```bash
docker compose up -d
./scripts/pull-model.sh llama3.2:3b
```

Затем открой в браузере http://localhost:3000

**Зачем:** локальная модель не имеет лимита запросов и не отправляет
твои данные наружу. Это страховка, когда облачный лимит кончился.

**Нормальный результат:** открылась страница Open WebUI, при первом входе
создаётся аккаунт (он локальный, хранится у тебя), в списке моделей видна
`llama3.2:3b`.

**Какую модель брать под твоё железо (облачный ПК ~16 GB RAM):**

| Модель | Размер файла | Нужно RAM | Комментарий |
|---|---|---|---|
| `llama3.2:1b` | ~1.3 GB | 4 GB | Самая быстрая, для простых задач |
| `llama3.2:3b` | ~2 GB | 6 GB | Хороший баланс, рекомендую начать с неё |
| `mistral:7b` | ~4.4 GB | 10 GB | Умнее, заметно медленнее на CPU |
| `gemma3:4b` | ~3.3 GB | 8 GB | Альтернатива, хорошо знает русский |

**Если результат другой:**
- `docker: command not found` — установи Docker Desktop с https://docs.docker.com/get-docker/
- Порт 3000 занят — поменяй в `docker-compose.yml` строку `"3000:8080"` на `"3001:8080"`
- Модель отвечает очень медленно — возьми модель меньше, начни с `llama3.2:1b`

### Дополнительные бесплатные варианты

| Провайдер | Лимит | Ключ | Где взять |
|---|---|---|---|
| Google AI Studio | Меняется часто, смотри https://aistudio.google.com/rate-limit | `GEMINI_API_KEY` | https://aistudio.google.com/apikey |
| GitHub Models | ~10 запросов/мин, ~50/сутки (public preview) | `GITHUB_MODELS_TOKEN` | https://github.com/marketplace/models, токен с правом `models:read` |
| OpenRouter | 20/мин и 50/сутки на моделях `:free` | `OPENROUTER_API_KEY` | https://openrouter.ai/keys |

Про Google AI Studio есть важная деталь: на бесплатном уровне Google может
использовать переданные данные для улучшения своих моделей, и правила
отличаются по регионам. Не отправляй туда личные документы и паспортные данные.

Про OpenRouter официально указано: 50 запросов в сутки на `:free`-моделях,
и 1000 в сутки после разовой покупки кредитов на $10
(https://openrouter.ai/docs/api-reference/limits). Разовая покупка — легальный
способ поднять лимит, а не обход правил.

## Шаг 2. Проверить, что доступ реально работает

**Что сделать:**

```bash
python3 kitai_cli.py doctor
```

**Зачем:** это не чтение конфига, а настоящие запросы к провайдерам.
Команда показывает, что работает прямо сейчас.

**Нормальный результат:**

```
  groq             РАБОТАЕТ — llama-3.1-8b-instant, 0.4 c
  ollama           РАБОТАЕТ — llama3.2:3b, 2.1 c
Рабочих способов доступа: 2 (groq, ollama)
```

**Если результат другой:**
- `нет ключа` — вернись к шагу 1
- `ключ не принят (401)` — ключ скопирован не полностью, создай новый
- `лимит исчерпан (429)` — суточный лимит кончился, работать будет следующий провайдер в цепочке
- `нет связи` у ollama — контейнер не запущен, выполни `docker compose up -d`

## Шаг 3. Моды агента

Мод — это дополнение, которое добавляет агенту новую способность.

**Посмотреть список:**

```bash
python3 kitai_cli.py mods list
```

**Установить:**

```bash
python3 kitai_cli.py mods install web-fetch
python3 kitai_cli.py mods install notes
python3 kitai_cli.py mods install strategy-tools
```

**Нормальный результат:** `Плагин установлен: plugins/web_fetch.py`

**Что дают встроенные моды:**

| Мод | Команда в агенте | Что делает |
|---|---|---|
| `web-fetch` | `/web URL` | Скачивает страницу и показывает текст без HTML |
| `notes` | `/note текст` | Сохраняет заметки между запусками |
| `strategy-tools` | `/strategy` | Переключение профилей прямо из чата |

**Проверить, что мод подключился:**

```bash
python3 local_agent.py
```

и внутри написать `/help` — новые команды должны появиться в списке.

### Моды-репозитории

Моды типа `repo` — это чужие проекты с GitHub. Правило жёсткое:

> **Скачать не значит запустить.** Код скачивается в папку `mods/` и
> никогда не выполняется автоматически. Перед запуском чужого кода
> прочитай README, лицензию и посмотри, что он делает.

```bash
python3 kitai_cli.py mods install open-webui
python3 kitai_cli.py mods remove open-webui
```

Скачивание разрешено только с `github.com`, `gitlab.com` и `codeberg.org`
и только по HTTPS. Это защита от подмены источника.

## Шаг 4. Настройка стратегии

Стратегия — это порядок, в котором пробуются провайдеры, и что делать при отказе.

**Посмотреть профили:**

```bash
python3 kitai_cli.py strategy
```

**Профили в комплекте:**

| Профиль | Для чего | Цепочка |
|---|---|---|
| `balanced` | По умолчанию, рабочий режим | groq → gemini → github → openrouter → ollama |
| `fast_free` | Когда нужна скорость | groq → groq 70B → gemini → ollama |
| `private_local` | Ничего не уходит наружу | только ollama |
| `deep_research` | Длинные тексты и разбор | gemini → groq 70B → github → mistral |
| `android` | Работа с телефона | groq → gemini lite → openrouter |

**Переключить:**

```bash
python3 kitai_cli.py strategy use fast_free
```

**Посмотреть, кто сработает первым:**

```bash
python3 kitai_cli.py strategy plan
```

Эта команда показывает всю цепочку и честно отмечает, какой шаг не готов и почему.

**Главное свойство стратегии:** если провайдер вернул `429` (лимит кончился)
или не отвечает, запрос автоматически уходит следующему в цепочке. Ты этого
не замечаешь — ответ просто приходит. В конце цепочки стоит локальная модель,
у которой лимита нет.

**Настроить формат ответов** — файл `config/strategy.json`, раздел `answer_format`.
Там же в `model_preferences.avoid_families` перечислены семейства моделей,
которые не предлагаются по умолчанию.

## Шаг 5. Задать вопрос

```bash
python3 kitai_cli.py ask "как проверить свободную память на Linux"
```

**Полный режим стратега** (со всеми разделами: цель, стратегии, проверка дыр, план):

```bash
python3 kitai_cli.py ask --strategist "как поднять локальную модель на 16 GB RAM"
```

**Посмотреть, кто и почему отвечал:**

```bash
python3 kitai_cli.py ask -v "привет"
```

**Разово использовать другой профиль или провайдера:**

```bash
python3 kitai_cli.py ask --profile private_local "личный вопрос"
python3 kitai_cli.py ask --provider groq --model llama-3.3-70b-versatile "сложный вопрос"
```

## Работа с телефона Tecno Camon 19 Pro

Телефон с 8 GB RAM не потянет большую модель локально — она будет греть
устройство и отвечать по несколько минут. Правильная схема: **считает
облако или домашний ПК, телефон только показывает**.

**Вариант 1 — только облако, ничего не настраивать:**

```bash
python3 kitai_cli.py strategy use android
```

**Вариант 2 — телефон подключается к домашнему ПК с Ollama:**

1. На ПК запусти Ollama так, чтобы она слушала сеть:
   переменная окружения `OLLAMA_HOST=0.0.0.0`
2. Узнай локальный IP компьютера (например `192.168.1.50`)
3. На телефоне открой в браузере `http://192.168.1.50:3000`

**Важно про безопасность:** открывай доступ только в своей домашней Wi-Fi
сети. Не выставляй Ollama и Open WebUI в интернет через проброс портов
без пароля — к твоей модели сможет подключиться кто угодно.

## Безопасность: что этот набор не делает

- Не создаёт мультиаккаунты и не обходит лимиты провайдеров
- Не запускает скачанный чужой код автоматически
- Не отправляет твои ключи никуда, кроме самого провайдера
- Не печатает ключи в логах — только маску вида `gsk_...ab`
- Не даёт моду `web-fetch` ходить по локальной сети (защита от доступа к твоему роутеру и служебным адресам)

Файл `.env` с ключами добавлен в `.gitignore`. Если ключ всё же попал в
публичный репозиторий — немедленно отзови его в панели провайдера и создай новый.
