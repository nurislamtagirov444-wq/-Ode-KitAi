# Android и локальные AI-модели без лагов

Главная идея: **не запускай тяжёлую модель на слабом Android**. Пусть модель работает на ПК/ноутбуке/VPS, а Android будет только интерфейсом через браузер.

## Лучший вариант

```text
Android Chrome/Firefox → Open WebUI на ПК → Ollama → модель
```

Запуск на ПК:

```bash
docker compose up -d
./scripts/pull-model.sh llama3.2:1b
```

Узнать IP ПК в локальной сети:

```bash
hostname -I
```

Открыть на телефоне:

```text
http://IP_ПК:3000
```

## Если телефон и ПК не в одной сети

Безопасные варианты:

- Tailscale;
- ZeroTier;
- свой VPN;
- reverse proxy с HTTPS и авторизацией, если понимаешь настройку безопасности.

Не открывай порт `3000` напрямую в интернет без защиты.

## Если хочется запускать прямо на Android

Это возможно только для маленьких моделей и часто будет медленно. Что пробовать:

- GGUF-модели 0.5B–1.5B;
- короткий контекст;
- quantized Q4/Q5;
- не держать много приложений в фоне.

На слабом Android большие модели 7B/8B обычно будут лагать или не загрузятся из-за RAM.

## Как уменьшить лаги

- бери модель меньше;
- уменьши context length;
- отключи параллельные ответы;
- не запускай несколько моделей одновременно;
- используй ПК/GPU/VPS как backend;
- подключайся к WebUI с телефона.
