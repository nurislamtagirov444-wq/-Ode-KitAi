# AI без скачивания модели: рабочая схема для Android

Пользователь не хочет скачивать локальную модель. Поэтому основной путь такой:

```text
Android / браузер
        ↓
Ode KitAi Web
        ↓
удалённый no-download AI-провайдер
```

Так модель не лежит на телефоне и не скачивается на ПК. Нужен интернет и выбранный провайдер.

## Реальность лимитов

100–200 GB трафика — это не то же самое, что 100–200 GB AI-лимита. AI-провайдеры обычно ограничивают:

- количество запросов в минуту/день;
- токены ввода/вывода;
- контекст;
- скорость;
- кредиты аккаунта;
- fair-use правила;
- доступные модели.

Поэтому стратегия не «один вечный безлимит», а несколько легальных провайдеров с быстрым переключением.

## Провайдеры в сайте

### 1. Pollinations

Плюсы:

- модель скачивать не надо;
- можно попробовать сразу;
- подходит для прототипа и простых задач.

Минусы:

- стабильность и лимиты не гарантируются;
- без ключа используется простой text endpoint;
- качество зависит от доступной модели.

Запуск:

```bash
./scripts/start-ai-site.sh
```

В сайте выбрать:

```text
No-download: Pollinations
```

### 2. Puter.js

Плюсы:

- работает прямо в браузере;
- серверный API key не нужен;
- можно использовать как вариант без локальной модели.

Минусы:

- может попросить вход в Puter;
- лимиты и доступ зависят от аккаунта и правил Puter;
- нельзя считать это гарантированным безлимитом.

В сайте выбрать:

```text
No-download: Puter.js в браузере
```

### 3. OpenRouter

Плюсы:

- много моделей;
- OpenAI-compatible API;
- удобно переключать модели.

Минусы:

- нужен API key;
- free-модели ограничены;
- ключ нельзя вставлять в чат.

Запуск:

```bash
OPENROUTER_API_KEY="твой_ключ" ./scripts/start-ai-site.sh
```

В сайте выбрать:

```text
No-download: OpenRouter через env key
```

### 4. Groq

Плюсы:

- быстрый inference;
- OpenAI-compatible API;
- есть free-tier.

Минусы:

- нужен API key;
- лимиты по аккаунту;
- список моделей меняется.

Запуск:

```bash
GROQ_API_KEY="твой_ключ" ./scripts/start-ai-site.sh
```

В сайте выбрать:

```text
No-download: Groq через env key
```

### 5. Custom OpenAI-compatible

Подходит для любого совместимого сервиса или gateway.

Запуск:

```bash
OPENAI_COMPATIBLE_BASE_URL="https://example.com/v1" \
OPENAI_COMPATIBLE_API_KEY="твой_ключ_если_нужен" \
./scripts/start-ai-site.sh
```

В сайте выбрать:

```text
No-download: свой OpenAI-compatible API
```

## Нулевая настройка

```bash
git clone https://github.com/nurislamtagirov444-wq/-Ode-KitAi.git
cd -Ode-KitAi
./scripts/start-ai-site.sh
```

Открыть на ПК:

```text
http://localhost:7860
```

Открыть на Android:

```text
http://IP_ПК:7860
```

В правой панели по умолчанию выбран:

```text
No-download: Puter.js в браузере
```

Если Puter.js не подходит, переключиться на:

```text
No-download: Pollinations
```

И написать:

```text
Сделай мне пошаговый план настройки бесплатного AI на Android без скачивания модели.
```

## Если не работает

1. Проверь интернет.
2. Переключись с Pollinations на Puter.js.
3. Если есть OpenRouter/Groq key — задай его через env и выбери провайдера.
4. Если сайт нужен только с телефона вне дома — используй Tailscale/ZeroTier, а не открывай порт в интернет.
5. Если провайдер упёрся в лимит — подожди или переключись на другой легальный провайдер.
