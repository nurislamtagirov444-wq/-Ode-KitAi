# Как дать агенту доступ читать GitHub

Есть 4 нормальных способа. Выбирай по тому, публичный репозиторий или приватный.

## 1. Самый простой способ: публичный GitHub-репозиторий

Если репозиторий публичный, доступ агенту давать не нужно.

Что сделать:

1. Открой репозиторий на GitHub.
2. Скопируй ссылку из адресной строки, например:

```text
https://github.com/open-webui/open-webui
```

3. Отправь агенту:

```text
Прочитай этот GitHub-репозиторий, README, issues/releases если нужно, и объясни, как его поставить: https://github.com/open-webui/open-webui
```

Что агент сможет сделать:

- открыть README;
- посмотреть структуру проекта;
- найти документацию;
- скачать/клонировать репозиторий, если у агента есть среда с `git`;
- сравнить с другими проектами.

## 2. Через текущий репозиторий Arena

Если ты работаешь в Arena Agent Mode внутри репозитория, агент уже может читать файлы этого репозитория через рабочую среду.

Попроси так:

```text
Осмотри текущий репозиторий: git status, README, структуру файлов, инструкции и скажи, что тут есть.
```

Или конкретнее:

```text
Прочитай файл prompts/arena-agent-mode-strategist-ru.md и улучши его под Arena Agent Mode.
```

Важно: если инструкция лежит в репозитории, агент может её прочитать как файл, но она не всегда автоматически становится системной инструкцией. Для надёжности копируй важный промпт в первое сообщение или Custom Instructions.

## 3. Приватный репозиторий через GitHub-интеграцию Arena

Если репозиторий приватный, обычной ссылки недостаточно. Нужно дать Arena доступ через GitHub-интеграцию.

Общий порядок:

1. Открой Arena.
2. Найди настройки подключения GitHub / Integrations / Connected accounts.
3. Подключи GitHub.
4. На стороне GitHub разреши доступ Arena к нужному репозиторию.
5. Вернись в Arena и создай/открой сессию именно с этим репозиторием.
6. Напиши агенту:

```text
Проверь текущий репозиторий: git status, README, package files, scripts, docs. Ничего не удаляй без моего подтверждения.
```

Если подключение сломано, агент обычно увидит ошибку авторизации при `git` или `gh`. Тогда нужно не давать токен в чат, а переподключить GitHub в Arena.

## 4. Приватный репозиторий без Arena-интеграции

Безопасные варианты:

### Вариант A: сделать репозиторий публичным

Подходит, если в проекте нет секретов, приватного кода и персональных данных.

### Вариант B: добавить нужные файлы в задачу

Можно прикрепить или вставить:

- `README.md`;
- `package.json` / `requirements.txt`;
- `docker-compose.yml`;
- список файлов;
- ошибку из терминала.

### Вариант C: локально клонировать и открыть в Arena

Если ты сам имеешь доступ к приватному репозиторию, можно открыть его как рабочий проект в среде, где агент уже имеет доступ к файлам.

Не делай так:

```text
Вот мой GitHub token: ghp_...
```

Токены, пароли, cookies, SSH private key и коды 2FA нельзя отправлять агенту в чат.

## Как дать ссылку с Android

1. Открой приложение GitHub или браузер.
2. Открой нужный репозиторий.
3. Нажми Share / Поделиться.
4. Выбери Copy link / Скопировать ссылку.
5. Отправь агенту ссылку.

Пример запроса:

```text
Прочитай этот GitHub-проект и скажи, можно ли его использовать как плагин для моего локального AI-kit. Проверь README, установку, лицензии, риски и дай пошаговую инструкцию: https://github.com/user/repo
```

## Как локальный агент из этого репозитория читает GitHub

В `local_agent.py` есть плагин:

```text
/github_clone URL [имя_папки]
```

Пример:

```bash
python3 local_agent.py
```

Потом внутри агента:

```text
/github_clone https://github.com/open-webui/open-webui.git
/readme mods/open-webui
```

Ограничение: этот плагин специально разрешает только HTTPS-репозитории с `github.com`, `gitlab.com`, `codeberg.org` и кладёт их в папку `mods/`. Он не запускает скачанный код автоматически — это защита.

## Формула правильного запроса агенту

Копируй и меняй ссылку:

```text
Прочитай GitHub-репозиторий: ВСТАВЬ_ССЫЛКУ

Сделай:
1. кратко объясни, что это;
2. проверь README, установку, зависимости, лицензии;
3. найди риски и логические дыры;
4. скажи, подходит ли это для Android/локального AI-kit;
5. если подходит — дай пошаговую установку с нуля;
6. не запускай подозрительный код без моего подтверждения.
```
