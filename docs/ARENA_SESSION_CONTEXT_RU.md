# Контекст продолжения Arena-сессии

Полный исходный архив переписки сохранён в корне репозитория в файле `Arena _ Benchmark & Compare the Best AI Models (2)` (MHTML). Этот документ — краткий, не содержащий секретов индекс текущего технического состояния.

## Цель

Собрать на Android/Termux + `proot-distro` Debian управляемого из терминала агента:

- **командир** — `fcc-claude` из `Alishahryar1/free-claude-code`;
- **мозг/маршрут** — `g4f api` без API-ключей;
- **руки для файлов** — встроенные средства агента, доступные внутри Debian;
- **руки для браузера** — Playwright MCP, подключаемый к Claude Code только после проверки базового ответа агента.

## Работающая инфраструктура

- `g4f api` запущен в отдельной Termux-сессии на `http://127.0.0.1:1337`.
- FCC запущен в отдельной сессии командой `/root/.local/bin/fcc-server`; Admin UI: `http://127.0.0.1:8082/admin`.
- В FCC исправлен `HOST=127.0.0.1` в `~/.fcc/.env`.
- В Providers у `llama.cpp Base URL` указан адрес g4f, модели обновились: интерфейс сообщил `264 models applied`.
- В Model Config предполагаемый маршрут: `Default Model = llamacpp/gpt-4o`; все отдельные маршруты Fable/Opus/Sonnet/Haiku должны быть `None`, чтобы не уходить на старый NVIDIA-маршрут.
- `fcc-claude` запускается командой `/root/.local/bin/fcc-claude` из новой Debian-сессии.

## Известная проблема

Первый большой запрос из Claude Code через автоматический маршрут g4f `gpt-4o` завершился в g4f ошибкой:

```text
TimeoutError: The operation timed out after 120 seconds
POST /v1/chat/completions -> 500
```

Это означает тайм-аут внешнего g4f-провайдера, а не неисправность FCC. Наличие названия в каталоге моделей не гарантирует работу в данный момент и не гарантирует поддержку инструментов/большого контекста. Перед подключением браузерных рук необходимо добиться стабильного короткого ответа от выбранного маршрута g4f.

## Руки и командир: найденное в старом чате

Старая концепция была: командир принимает русские задания, а Playwright MCP даёт ему браузерные действия (открыть страницу, читать DOM/снимок, нажать, напечатать). Chromium и Chromium Headless Shell уже скачаны в Debian в `~/.cache/ms-playwright/`.

Состояние браузерных рук:

- системные зависимости Chromium ещё не были установлены (`npx playwright install-deps chromium` не выполнен);
- `@playwright/mcp` ранее был удалён во время очистки старых командиров;
- старые конфиги `~/.gemini/settings.json` и `~/.codex/config.toml` нельзя использовать для текущего FCC/Claude Code;
- Playwright MCP нужно подключать **собственной командой Claude Code** после базовой проверки FCC. Актуальный формат Claude Code: `claude mcp add ...`.

Не добавлять Playwright MCP до базового успеха: браузерные инструменты заметно увеличивают размер запроса и могут усугубить тайм-ауты g4f.

## Предпочтения и ограничения

- Использовать стек из выбранных пользователем GitHub-репозиториев: FCC и g4f-working.
- Не предлагать старые удалённые маршруты/провайдеры без отдельного запроса.
- Не сохранять и не выводить API-ключи, токены, cookies или другие секреты.
- Не останавливать окна `g4f api` и `fcc-server` с помощью `Ctrl+C`, пока идёт настройка.
