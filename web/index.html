Нулевая настройка

Минимальный путь

  1. Запусти Ollama + Open WebUI: docker compose up -d
  2. Скачай модель без платного API: ./scripts/pull-model.sh llama3.2:1b
  3. Запусти этот сайт: python3 web/server.py --host 0.0.0.0 --port 7860
  4. Открой на ПК: http://localhost:7860
  5. Открой на Android: http://IP_ПК:7860

Не публикуй этот сайт в интернет без пароля, HTTPS и понимания безопасности. Для удалённого доступа лучше Tailscale или ZeroTier.
