# Ode KitAi Web

Это простой сайт для локального бесплатного AI через Ollama. Он не использует платный API. Модель должна быть запущена локально на ПК/сервере, а Android может открывать сайт через браузер.

## Быстрый запуск без Docker

Из корня репозитория:

```bash
python3 web/server.py --host 0.0.0.0 --port 7860
```

Открыть на ПК:

```text
http://localhost:7860
```

Открыть на Android в той же Wi‑Fi сети:

```text
http://IP_ПК:7860
```

## Запуск через Docker Compose

```bash
docker compose up -d
```

Открыть сайт:

```text
http://localhost:7860
```

Open WebUI останется на:

```text
http://localhost:3000
```

## Что должно быть до запуска

Нужен Ollama и скачанная модель. Через этот репозиторий:

```bash
docker compose up -d ollama
./scripts/pull-model.sh llama3.2:1b
```

Или если Ollama установлен отдельно:

```bash
ollama pull llama3.2:1b
ollama serve
```

## Настройки модели

В интерфейсе можно менять:

- модель, например `llama3.2:1b`, `llama3.2:3b`, `gemma2:2b`, `phi3:mini`, `mistral:7b`;
- temperature;
- размер контекста;
- максимум ответа;
- системный промпт.

Для слабого железа начинай с маленькой модели и коротких ответов.

## GitHub-моды

Сайт содержит каталог `web/config/mods.json`. Он показывает полезные open-source проекты и команды клонирования. Сайт не запускает чужой код автоматически.

Чтобы добавить мод в каталог, добавь объект в `web/config/mods.json`:

```json
{
  "name": "Название",
  "category": "webui",
  "repo": "https://github.com/user/repo",
  "description": "Что делает проект",
  "tags": ["tag1", "tag2"],
  "risk": "Что проверить перед запуском"
}
```

## Безопасность

- Не открывай сайт в интернет без авторизации и HTTPS.
- Для доступа с телефона из другой сети лучше используй Tailscale или ZeroTier.
- Не вставляй токены, пароли, cookies и приватные ключи в чат.
- Не запускай неизвестные GitHub-проекты без чтения README и проверки зависимостей.
