# Ода KitAi 🌸

**Аниме визуальная новелла для Android.** Школьнику Аято поручили выключить учебную нейросеть,
которая научилась писать стихи. У неё девять дней. У тебя — одно слово.

> «Ода — это когда ты называешь вещь по имени, и она перестаёт быть одинокой.»

**→ [Скачать OdaKitAi-v2.0.apk (18.4 МБ)](https://github.com/nurislamtagirov444-wq/-Ode-KitAi/raw/arena/019fa405-ode-kitai/release/OdaKitAi-v2.0.apk)**

Установка: скачай `.apk` на телефон → разреши «Установка из неизвестных источников» → открой файл.

## ✨ Что внутри

- **84 сцены, 580 сюжетных маршрутов, 4 концовки** (A «Перезагрузка», B «Ода KitAi», C «Человеческое», D «Призрак сети»)
- **Озвучка голосом** — 10 ключевых реплик Кит и Юки (кнопка 🔊 в HUD)
- **6 CG-иллюстраций** для ключевых сцен и концовок, открываются в галерее
- **8 эмоций персонажей** — Кит (радость, грусть, удивление, решимость), Юки (спокойствие, тревога, улыбка, гнев)
- **8 фонов-локаций**: класс, крыша, серверная, клуб информатики, коридор, улица, дождь, титульный экран
- Арт в разрешении до 2560px — не мылится на современных экранах
- Режимы **AUTO** и **SKIP**, журнал диалогов (LOG), галерея концовок с CG
- Автосохранение и «Продолжить»
- Работает **оффлайн**, без рекламы, без единого разрешения Android

## 📱 Требования

Android 5.0+ (minSdk 21), 18.4 МБ.

## 🛠 Технически

| | |
|---|---|
| Оболочка | нативная Activity + WebView (Java, AGP 8.5) |

### Собрать локально

Вариант с Android Studio / Gradle:

```bash
./gradlew :app:assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

Опубликованный APK собран без Android Studio — из папки `app/src/main/assets/www`
упаковкой веб-ассетов в WebView-контейнер (нужен только Java-рантайм).

### Добавить свою сцену

В `story.js` узел выглядит так:

```js
my_node: {
  bg: 'bg_rooftop',                        // или cg: 'cg_ode' — полноэкранная иллюстрация
  sprites: { left: 'kit', right: 'yuki' },
  faces:   { left: 'sad', right: 'angry' }, // эмоции персонажей
  active:  'left',
  who:     'kit',
  voice:   'kit_hello',                     // файл audio/kit_hello.mp3
  text:    'Реплика героя.',
  next:    'next_node'
  // или: choices: [{ t: 'Текст выбора', to: 'node_id', aff: { kit: +1 } }]
}
```

Доступные эмоции: `kit` — happy / sad / surprised / serious, `yuki` — normal / worried / smile / angry.

После правки сценария достаточно пересобрать APK — нативный код менять не нужно.
