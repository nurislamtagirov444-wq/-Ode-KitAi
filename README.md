# -Ode-KitAi 🛠️

Мой первый кит для создания сверхэффективных стратегий с помощью ИИ.

## Что внутри:
- `/core`: Основные промты (включая **Архитектора-Стратега**).
- `/guides`: Карты ресурсов и инструкции по обходу ограничений.
- `/templates`: Шаблоны для запуска на разном железе.

## Как запустить "Архитектора-Стратега":
1. Перейдите в папку `core/strategist_v1.md`.
2. Скопируйте текст промта.
3. Используйте в любой современной LLM (Claude, GPT-4, Gemini).
